How we measured

Local 10- and 30-minute samples on a 24 GB Apple Silicon Mac. CPU is a time-based process average; mounted memory includes ntfsmac and its private filesystem runtime. Battery wording is an estimate based on measured CPU activity and wakeups, not a battery-life guarantee. Values are rounded up for a clear, conservative summary.

Small app, serious boundary

Your NTFS drive in the menu bar.

ntfsmac runs the filesystem in a lightweight Linux virtual machine and exposes the result locally to macOS. The interface keeps mount state, safety checks and recovery close at hand.

  • Modern macOS helper in the standard installer
  • Legacy compatibility installer released alongside it
  • Plain-language diagnostics with clear OK, idle and attention states
  • Safe Quit confirmation whenever a drive is still mounted
  • Per-mount isolation, verified copy and complete uninstall

The 3.1 interface

Useful detail, without the internals.

Diagnose groups the real checks into four readable outcomes. Settings keeps navigation, version and update check on one line. When storage is active, Quit makes the safe choice explicit instead of silently leaving services behind.

Installation

Three deliberate steps.

Choose the standard DMG for current macOS releases. The separately labelled Legacy DMG remains available for compatibility and installs the same visible ntfsmac app.

1

Download

Get the latest signed Apple Silicon DMG from GitHub Releases.

2

Move

Drag ntfsmac to Applications and open it.

3

Authorize

Allow ntfsmac in Login Items and grant Full Disk Access when macOS asks.

Upgrading to the standard 3.1 build verifies its modern helper first, then removes the retired Legacy helper. macOS may ask you to approve access again.

Security & privacy

No telemetry. No silent updater.

The app checks GitHub at most once every 24 hours for the latest published release. It never downloads or installs updates on its own. Automatic network errors stay silent and mount operations do not depend on the check.
