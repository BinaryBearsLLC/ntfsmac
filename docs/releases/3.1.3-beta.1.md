# ntfsmac 3.1.3 Beta 1

An optional preview for Apple Silicon Macs running macOS 14 Sonoma or newer.
The stable release remains 3.1.2. Use backed-up or disposable media for beta testing.

## Changes

- Updated ntfs-3g to 2026.7.7 and anylinuxfs to 0.19.0, with exact dependency,
  toolchain and Alpine package locks.
- Corrected mixed-drive detection: an exFAT partition is no longer labelled NTFS
  merely because it uses a Windows-family partition type.
- Standard installer only. Legacy distribution is deprecated; migration code is retained.
- macOS 14 deployment target, with newer-OS features enabled only where available.
- A one-time compatibility notice and expanded, local-only diagnostic JSON.
- Diagnose and Command-click export remain accessible on runtime discovery errors.
- Centered Binary Bears attribution and consistent Quit-button sizing.
- Shorter development guides and separate stable/beta download channels.

## Compatibility and feedback

Native M5 testing on macOS 26.6.2 has verified the updated runtime and NTFS
write/flush/remount/SHA-256 operations. Earlier candidate testing also covered ext2,
ext3 and ext4; consult the linked record for the exact build tested for each operation.
Sonoma 14.6.1 VM checks cover app/helper execution, not filesystem read/write:
that guest does not expose the nested Hypervisor access required by the runtime.
Native Sonoma and other Mac/OS combinations are not yet fully qualified.

Report successful configurations as well as problems through
[GitHub Issues](https://github.com/BinaryBearsLLC/ntfsmac/issues/new/choose).
Include the version/build, macOS version, chip, filesystem and operations completed.
Hold Command while clicking Diagnose to export JSON; review it before attaching.
Nothing is uploaded automatically.

Do not erase or repair a disk to reproduce a problem unless it is an expendable
test device. This beta does not claim universal macOS 14+ hardware coverage.
The versioned validation record accompanies the source; automated checks,
physical-media tests and notarization are reported separately.
