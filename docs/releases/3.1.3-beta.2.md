# ntfsmac 3.1.3 Beta 2

Optional preview for Apple Silicon Macs running macOS 14 Sonoma or newer.
The stable release remains 3.1.2. Use backed-up or disposable media for beta testing.

## Changes

- ntfs-3g 2026.7.7 and anylinuxfs 0.19.0, with exact dependency, toolchain and Alpine package locks.
- Correct filesystem detection when NTFS and non-NTFS drives are connected together.
- One Standard installer; Legacy distribution is deprecated, with migration code retained.
- macOS 14 deployment target and guarded newer-system features.
- A one-time compatibility notice and local-only Command-click Diagnose JSON export.
- Diagnostics remain available when drive discovery fails, without widening the popover
  or reporting an incomplete preparation as Ready.
- Centered Binary Bears attribution, consistent Quit sizing and shorter development guides.

## Compatibility and feedback

The official notarized build 31304 passes native M5/macOS 26.6.2 write, flush,
unmount/remount and SHA-256 checks for NTFS, ext2, ext3 and ext4. Each filesystem
was tested separately. App/helper updates and simultaneous NTFS/EXT detection
were also checked. The same app passes Gatekeeper and UI/diagnostic checks in Sonoma.

Native M5/macOS 26.6.2 testing and local Sonoma 14.6.1 VM checks are recorded
separately in the [validation record](https://github.com/BinaryBearsLLC/ntfsmac/blob/Update/3.1.3/docs/testing/BINARYBEARS_V3_1_3_INSTALLED_2026-09-08.md).
The Sonoma VM validates app behavior, not filesystem read/write: its nested
Hypervisor access is unavailable. Other Mac/OS combinations remain community-preview
coverage, not a universal compatibility guarantee.

Report successful configurations or problems through
[GitHub Issues](https://github.com/BinaryBearsLLC/ntfsmac/issues/new/choose).
Include version/build, macOS version, chip, filesystem and operations completed.
Hold Command while clicking Diagnose to export JSON; review it before attaching.
Nothing is uploaded automatically.

Beta 1 was an internal candidate and was not published as a download.
