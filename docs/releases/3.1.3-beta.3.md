# ntfsmac 3.1.3 Beta 3

Preview for Apple Silicon, macOS 14+. Stable remains 3.1.2.

## Improvements

- Detect supported partitions on multi-partition MBR SSDs, including Linux entries.
- Display the verified filesystem and volume label before mounting. Unreadable metadata stays explicitly unverified.
- Add `ntfsmac filesystem diskNsM` for read-only filesystem identification from the CLI.
- Bundle the complete runtime in the compressed DMG: installation and first initialization require no package or image downloads.
- Store runtime payloads in Git with checksums and provenance; refresh seven related Alpine packages to replace unavailable pinned downloads.

## Validation

GUI and CLI tested on a physical Apple Silicon Mac: two simultaneous EXT4 mounts,
write/remount/SHA-256 verification, cleanup and preservation of the native FAT32 sibling.
Fresh runtime initialization also passed with outbound networking denied.
Other Mac/macOS combinations remain beta coverage; no new NTFS, ext2, ext3 or native Sonoma qualification is claimed.

Use backed-up test media. Report version/build, macOS, chip and filesystem through
[GitHub Issues](https://github.com/BinaryBearsLLC/ntfsmac/issues/new/choose).
